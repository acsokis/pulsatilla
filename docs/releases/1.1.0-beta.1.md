# Pulsatilla Community 1.1.0-beta.1

Release date: **6 October 2026**. Milestone: **M2026-10-NETWORK-FIRST**.
This is an early Community preview, published as a GitHub prerelease.

## Editions

Community is free and open source under MIT, with no account/payment/activation gate.
Its scope is local network visibility, inspection, active diagnostics and advisory
security/email/file review. PayPal support is voluntary and does not unlock features.

Core development is maintained in a separate private repository; its source and
internal materials are not included in this public repository or release package.
Core's proposed native C++/Qt, advanced WFP, encrypted P2P/chat/channels and managed
services remain roadmap items, not available or paid-upgrade promises. Existing MIT
notices and rights remain applicable to inherited MIT components.

## Install

Download `pulsatilla-1.1.0-beta.1-win-x64.zip`, verify its SHA-256 using the attached
hashlist, extract it and run `Pulsatilla.exe`. Install the **.NET 8 Windows Desktop
Runtime x64** separately. The executable is unsigned. Elevate only when an explicitly
requested capture, firewall or installed-VPN operation requires it.

## Included

- Network-first navigation and a persistent Inspect Traffic / Stop Inspection state.
- Native Windows paths/routes, grouped adapters, routed AUTO selection and explicit metrics.
- Native application/socket summary, endpoint-aware traffic and bounded packet HEX preview.
- Local file hashes/embedded signature results, byte-pattern indicators and MIME attachments.
- Asynchronous bounded email import, message paste/drop and local phishing indicators.
- Explicit installed-Defender scan and a bounded, confirmed active TCP banner read.
- Experimental installed-OpenVPN certificate-profile integration and manual privacy checks.

## Limits

These are advisory diagnostics. A byte-pattern match is not an attack or malware verdict;
UDP endpoint ownership can be ambiguous and stays Unknown. Raw inspection covers the
selected interface's supported IPv4 socket capture, not universal wire coverage or
decrypted TLS. The UI preview is bounded; discarded samples are not retained evidence.
Catalog signatures/current revocation are not fully established by the Community
embedded-signature check. VPN/password/MFA/unsupported-profile states are explicit.
No kill switch, split routing, secure chat, cloud breach lookup or hosted subscription
is delivered in this beta. Defender can use its own configured cloud protection.
Real VPN, privileged mutation, clean-machine installer, hardware/sleep/recovery and
actual DPI checks remain unverified. New text may use English fallback.
