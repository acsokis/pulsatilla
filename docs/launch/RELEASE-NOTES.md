# Pulsatilla Community 1.0.0

**Network clarity. Security insight.**

An early Windows x64 release by **Gábor Kocsis / Gabor Web**, under the MIT license.

- Amber download / purple upload adapter timeline and local application traffic views.
- Security review indicators and expandable IP/software source details.
- Explicit Windows Firewall application rules and local pasted/imported email review.
- Dark, Light and Windows themes, optimized Matrix background and embedded creator/docs.

## Run

Download `pulsatilla-1.0.0-win-x64.zip`, verify it using the supplied SHA-256 checksums,
extract it and run `Pulsatilla.exe`. Install **.NET 8 Windows Desktop Runtime x64** first.
The EXE is unsigned. Packet capture and confirmed firewall changes require Administrator
rights; the adapter Dashboard does not.

Security findings are review indicators, not attack proof or protection guarantees.
Email/exposure review is local: this release has no mailbox integration, VPN or external
dark-web/breach lookup. The MIT Community core requires no account or activation.
Setup, support and integrations are planned commercial options; no paid subscription is active.

Voluntary development support: [PayPal.Me / gaborcarter](https://paypal.me/gaborcarter).
The MIT Community core remains available without payment; support does not buy a service.
