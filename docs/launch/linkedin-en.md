I’m introducing Pulsatilla, my open-source Windows network tool from Gabor Web.

Network clarity. Security insight.

Pulsatilla brings live traffic, application activity and local security review into one desktop interface:

• An amber download / purple upload timeline reads Windows counters for the selected network adapter.
• Administrator-enabled IPv4 packet capture adds flow details and local application attribution. Very short connections can remain unattributed.
• Local indicators highlight patterns worth reviewing, such as scan-like traffic and repeated RDP connection attempts.
• Email review examines content you explicitly paste or import. Application blocking uses Windows Firewall and requires confirmation.

The Community core is MIT-licensed, with no account or activation gate. The commercial direction is separate: assisted setup, diagnostics, training, support and custom integrations. Later possibilities include managed reports and an opt-in exposure service using a configured external provider.

These paid services are planned; pricing, service terms and subscriptions are not active. The current release reviews imported exposure reports locally and makes no external breach lookup. Security findings are review indicators, not proof of an attack or guaranteed protection.
